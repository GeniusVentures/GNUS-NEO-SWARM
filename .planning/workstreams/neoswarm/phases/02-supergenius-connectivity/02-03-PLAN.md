  <action>
Wire together the full dispatch pipeline in SuperGeniusClient::SubmitJob():
```
SubmitJob(gnus_schema_json):
  1. Verify channel is connected — if not, try reconnect
  2. taskId = job_submitter_->PublishJob(gnus_schema_json)
  3. result = result_collector_->WaitForResult(taskId, config_.result_timeout_)
  4. Return result (vector<uint8_t>)
```

Gating: if Connect() was never called or channel is dead, attempt one reconnect cycle. If reconnect fails, return Error::NetworkError.
</action>
