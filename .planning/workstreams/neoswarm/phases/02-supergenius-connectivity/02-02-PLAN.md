  </read_first>
  <action>
Implement SGChannelManager:
- CreateChannel(endpoint, tls_ca_path, tls_cert_path) → outcome::result<void>
  - If endpoint is "localhost:50051" and no TLS certs: use grpc::InsecureChannelCredentials() with WARN log
  - If endpoint is non-localhost OR TLS certs provided: use grpc::SslCredentials() — HARD requirement
  - Store as shared_ptr<grpc::Channel> for reuse across jobs
- Set up gRPC keepalive: GRPC_ARG_KEEPALIVE_TIME_MS=30000, GRPC_ARG_KEEPALIVE_TIMEOUT_MS=10000
- HealthCheck() → outcome::result<bool> — try a simple RPC or channel state check
- Reconnect() with exponential backoff: 1s → 2s → 4s → 8s → 16s → max 30s between attempts
  - On connect failure, log error and schedule retry
  - Max 5 reconnect attempts before returning failure
- GetChannel() → shared_ptr<grpc::Channel>

Use gRPC v1.78.x stable APIs. Prefer grpc::CreateChannel() over deprecated grpc::CreateCustomChannel().
</action>

  - Insecure localhost allowed with WARN log
  - Exponential backoff reconnect implemented
  - Keepalive pings configured at 30s intervals
  - HealthCheck returns false for unreachable nodes
  </acceptance_criteria>
