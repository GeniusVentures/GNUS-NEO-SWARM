| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-03-15 | Information Disclosure | gcs_db status field | accept | Boolean subsystem state exposed to the embedding process only (same trust domain as existing supergenius_connected field); no keys/paths in status JSON |
| T-03-16 | Denial of Service | Idempotent re-init | mitigate | Existing guard preserved: repeat GeniusElmInit returns OK without re-running the chain; a second call with different config cannot corrupt the live instance |
