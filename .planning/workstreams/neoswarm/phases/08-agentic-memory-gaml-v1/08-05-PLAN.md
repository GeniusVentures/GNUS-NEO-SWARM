```cpp
    void ApiServer::IngestMemory(const InferenceResponse& resp, const Task& task)
    {
        if (!m_memoryGovernor || !m_memoryStorage || !m_memoryStorage->IsOpen()) return;
        memory::FactExtraction extractor;
        auto extractedRes = extractor.Extract(resp.m_output, task);
        if (!extractedRes.has_value() || extractedRes.value().empty()) return;
        memory::ContextMapping mapper;
        auto mapped = mapper.Map(std::move(extractedRes.value()), task);
        memory::WriteEvaluation evaluator;
        auto acceptedRes = evaluator.Evaluate(std::move(mapped), m_memoryStorage.get());
        if (acceptedRes.has_value() && !acceptedRes.value().empty())
        {
            auto putRes = m_memoryStorage->PutBatch(acceptedRes.value());
            if (!putRes.has_value()) ServerLogger()->warn("Memory ingestion PutBatch failed");
            else ServerLogger()->debug("Memory ingested {} facts", acceptedRes.value().size());
        }
    }
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Inference output → IngestMemory | Untrusted LLM output text flows through fact extraction regex → could contain adversarial patterns |
| Task prompt → Process inline needs_retrieval | User prompt analyzed by PromptAnalyzer for complexity/grounding → determines whether to trigger memory retrieval |
| ApiServer → MemoryStorage RocksDB | ApiServer is the sole writer to memory.db (Phase 8 local-only) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-17 | Denial of Service | Process inline PromptAnalyzer per request | accept | PromptAnalyzer::Analyze() is CPU-bound regex — bounded input, no I/O. Complexity scoring is O(n) on prompt length. Acceptable overhead on inference request path |
| T-08-18 | Information Disclosure | IngestMemory feeding inference output to storage | accept | Phase 8 is local-only; inference output is already visible to the local node. No cross-node exposure. Phase 10 will add encryption and privacy scoping |
| T-08-19 | Elevation of Privilege | ELMChainBuilder enable_memory_retrieval_ flag | mitigate | Flag defaults to true but can be set to false in Config. No runtime toggle without recompilation → prevents dynamic bypass of memory retrieval |
| T-08-20 | Tampering | IngestMemory called in all 3 execution paths | accept | RunSingleNode, RunSpecialist, RunSwarm all call IngestMemory — consistent but attacker can't selectively skip ingestion without code modification. Phase 9 will add attestation chain |
</threat_model>
