<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI args → PipelineRunner | Untrusted user input (`--niche`, `--from-stage`, `--config`) |
| PipelineRunner → subprocess | Command strings built from internal data; args passed as list (not shell string) |
| Subprocess → filesystem | Stage scripts write to artifacts/ and models/ — validate outputs before marking complete |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Injection | PipelineRunner._run_stage | mitigate | Commands built as lists (not shell strings); `subprocess.run(cmd, ...)` with `cmd` as list — no shell injection. `--niche` value is validated against `pipeline.specialists` list before use. |
| T-03-02 | Tampering | CheckpointValidator | mitigate | Checkpoint JSON files validate stage outputs before marking complete; manual editing of checkpoint files would still pass `is_complete()` but the validation is re-run on `--force` |
| T-03-03 | Denial of Service | Subprocess timeout | mitigate | `timeout=3600` per stage prevents hung processes from blocking pipeline indefinitely |
| T-03-04 | Information Disclosure | stderr capture | mitigate | stderr captured and only printed on failure (last 10 lines); no sensitive data in stage commands themselves |
| T-03-SC | Tampering | pip installs | mitigate | No new pip packages added in this plan |
</threat_model>
