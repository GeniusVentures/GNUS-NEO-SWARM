<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User query -> Router | Query string enters classification — untrusted input crosses here |
| Router -> Specialist selection | Classification result determines which model processes the query |
| YAML config -> Router | Router rules loaded from config — misconfiguration could misroute |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | Spoofing | router/rules.py keyword matching | accept | Prompt injection via query strings cannot trick router because classification is purely pattern-based (not LLM-based). Queries containing rule-triggering keywords (e.g., "def malicious_code") intentionally route to the matching specialist — this is BY DESIGN for rules-based routing. |
| T-02-06 | Denial of Service | router/rules.py regex matching | mitigate | Regex patterns compiled via re.compile(). Limit time complexity by constraining pattern length (< 200 chars). Per-pattern match attempts limited to ~1ms via simple patterns (no catastrophic backtracking). Rule matching aborts and returns empty if any single match takes > 100ms wall time (Python time.monotonic() guard). |
| T-02-07 | Tampering | router/schema.py YAML loading | mitigate | router_rules.yaml loaded via yaml.safe_load() (NEVER yaml.load()). Schema validation at load time catches malformed rules before state machine consumes them. Malformed rules produce clear error, not silent misclassification. |
| T-02-08 | Tampering | router/classifier.py JSON export | accept | router_rules.json is a derived file (regenerated from YAML). Tampering with it is self-correcting — next RouterClassifier init overwrites it from YAML. |
| T-02-09 | Elevation of Privilege | router/classifier.py fallback chaining | mitigate | Ultimate fallback to encyclopedic specialist ensures no query goes unhandled. Priority ordering is deterministic (by integer priority). No path exists to bypass fallback entirely — the encyclopedic always_match rule at priority 0 is the final safety net. |
| T-02-SC | Tampering | pip install transitions | mitigate | transitions 0.9.3 already installed and verified via pip show + import test. No new package installs in this plan. |
</threat_model>
