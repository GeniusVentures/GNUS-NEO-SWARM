    Class: ConvergenceTracker
    Constructor: __init__(target: float, warning: float, hard_stop: float, patience: int = 100, min_delta: float = 0.01, window_size: int = 20)
    Public method: step(loss: float, step_number: int) -> str
      Returns one of: "continue", "warning", "converged", "early_stop", "hard_stop"
    Properties: converged (bool), converged_at_step (int|None), aborted (bool), best_loss (float), losses (list), warnings (list)
    Private: _rolling_average() -> float (returns mean of last window_size losses, or inf if empty)

    Algorithm (per D-02/D-04):
    1. Append loss to self._losses
    2. If loss > hard_stop -> set aborted=True, return "hard_stop"
    3. If loss > warning -> append step_number to warnings, set status="warning"
    4. If loss < best_loss - min_delta -> update best_loss, reset no_improvement_steps=0
       else -> no_improvement_steps += 1
    5. If rolling_average < target AND not already converged -> set converged=True, converged_at_step=step_number, return "converged"
    6. If no_improvement_steps >= patience -> return "early_stop"
    7. Return status ("continue" or "warning")

    Import pattern: import logging; logger = logging.getLogger(__name__) (no print() in library code).
    No exceptions in hot path — return status strings. Caller (Distiller) decides action.
  </action>
