# **9\. Execution Modes**

---

## **Mode 1 — Single Node**

* Core LLM only.
* Fast.
* Minimal overhead.

---

## **Mode 2 — Specialist Mode**

* Core \+ Grammar OR Math.
* Sequential execution.

---

## **Mode 3 — Swarm Mode**

* Multiple nodes execute.
* Weighted consensus.
* Reputation-based selection.
